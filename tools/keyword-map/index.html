Keyword Map

A keyword map is a spreadsheet that assigns target keywords (and their intent categories) to specific pages, ensuring no two pages compete for the same query, a problem called keyword cannibalization. It also reveals which keywords have no page yet, feeding directly into a content production backlog. For established sites, the keyword map begins as a cleanup exercise; for new sites, it is a planning tool used before content is written.

Assigns target keywords to specific pages so no two pages compete.

One keyword intent → One canonical page

When to use this

  • When organic rankings plateau despite publishing on relevant topics, often a sign of cannibalization.
  • When auditing a large site where page ownership and keyword targeting evolved without coordination.
  • Before publishing new content in a competitive category, to confirm a page for the target intent does not already exist.
